## Известные ограничения плана

- API-003 остаётся частично покрытым: доступный API не даёт независимого оракула глобальной уникальности ID разных
  сущностей.
- Для `total` при разных `page_size` и `country_code` есть characterization assertions; контрактная семантика этих
  комбинаций требует уточнения.
- Минимумы, значения по умолчанию и формат ошибок для некоторых параметров в `tz-extracted.txt` повреждены/не читаются;
  проверки таких значений не следует представлять как контрактные требования.

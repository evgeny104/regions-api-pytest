# BUG-003 — Без параметра page_size API возвращает 10 элементов вместо 15

**Severity:** Не определена
**Priority:** Не определён
**Component:** `GET /1.0/regions` — пагинация
**Env:** `{BASE_URL}`
**Reporter:** Не указан
**Date:** 2026-11-02

## Описание

Запрос без параметра `page_size` возвращает 10 элементов. По контракту размер страницы по умолчанию — 15.

## Нарушенное требование

В `tz.pdf`, стр. 2, для `page_size` указаны допустимые размеры страниц 5, 10 и 15; значение по умолчанию — 15.

## Воспроизведение

1. Отправить `GET {BASE_URL}` без query-параметров.
2. Посчитать количество объектов в массиве `items`.

## Ожидаемый результат

Успешный ответ содержит 15 элементов в `items`.

## Фактический результат

В полном прогоне pytest от 2026-11-02 ответ имел статус `200`, но в `items` находилось 10 элементов.

## Evidence

Падение `test_page_size_default_value`: проверка `len(data["items"]) == 15` получила значение `10`.

## Связанный регрессионный тест

`tests/func/test_page_size.py::TestRegionsPageSize::test_page_size_default_value`

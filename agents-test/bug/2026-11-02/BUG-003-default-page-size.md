# BUG-003 — Наблюдение: без page_size API возвращает 10 элементов

## Наблюдение

Запрос без параметра `page_size` в прогоне от 2026-11-02 вернул 10 элементов.
Это наблюдение само по себе не подтверждает дефект: ожидаемое значение по
умолчанию нельзя прочитать в доступном контракте.

## Требование и ограничение

В `tz-extracted.txt`, стр. 2, значение `page_size` по умолчанию заменено
NUL-символами. Значение `15`, указанное в старом тесте, не подтверждено этим
извлечённым контрактом. Поэтому сравнение «10 вместо 15» не считается
подтверждённым нарушением.

Для подтверждения необходимо восстановить исходное значение из документа
контракта либо получить уточнение от его владельца.

## Воспроизведение наблюдения

1. Отправить `GET {BASE_URL}` без query-параметров.
2. Посчитать количество объектов в массиве `items`.

## Фактическое наблюдение

В полном прогоне pytest от 2026-11-02 ответ имел статус `200`, а в `items`
находилось 10 элементов.

## Evidence

Падение `tests/func/test_page_size.py::TestRegionsPageSize::test_page_size_default_value`:
assertion ожидал 15 и получил 10. Ожидаемое значение 15 сейчас не считается
контрактным требованием.
